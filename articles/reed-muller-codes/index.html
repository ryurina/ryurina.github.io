Coding theory

Reed–Muller codes from the polynomial side

Building the codes as evaluations of low-degree Boolean polynomials, and reading off their parameters.

02 Jul 2026 · 2 min read
  • Error correction
  • Boolean functions
  • Linear algebra

There are two standard ways into Reed–Muller codes. One is recursive, built out of the Plotkin construction. The other treats codewords as truth tables of low-degree polynomials. The second one is the reason the parameters are memorable, so that is the one I want to write out.

Codewords as truth tables

Fix mmm variables over the binary field. A Boolean function is a map from all 2m2^m2m input vectors to a single bit, so writing down its outputs in a fixed order gives a binary string of length 2m2^m2m.

Now restrict to functions represented by multilinear polynomials of total degree at most rrr. The set of all their truth tables is the Reed–Muller code, written RM(r, m).

Why multilinear

Over the binary field each variable satisfies x2=xx^2 = xx2=x, so every monomial can be reduced until no variable appears more than once. Multilinear polynomials are not a restriction — they are the whole space.

Reading off the parameters

The length is immediate: one coordinate per input vector, so N=2mN = 2^mN=2m.

The dimension counts monomials of degree at most rrr in mmm variables, which is a sum of binomial coefficients — one term per admissible degree.

The minimum distance is the interesting one. A nonzero polynomial of degree ddd vanishes on at most half of the cube for each degree it carries, so the minimum distance is 2 raised to the power m−rm - rm−r. Small degree means the polynomial cannot be zero very often, which means codewords stay far apart.

The trade-off in one sentence

Raising rrr adds monomials and therefore rate, and simultaneously halves the minimum distance. The parameter rrr is a dial between how much you can say and how badly the channel is allowed to garble it.

Where they show up

RM(1, 5) was the code on Mariner 9. More recently, polar codes — which are in 5G — are close relatives, built from the same recursive structure with a different rule for choosing which rows to keep.

Still working on

I want to write the recursive Plotkin view next and show it produces the same code, then implement majority-logic decoding to see the redundancy do its work.
