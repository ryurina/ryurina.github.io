Lagrange interpolation

An interactive study of polynomial interpolation, node placement and where the error actually comes from.

  • Numerical analysis
  • Visualisation
  • Python
Complete

Overview

A small tool for building interpolating polynomials through a set of points and watching what happens when you move the points around. It started as coursework and turned into the thing I use to explain why equally spaced nodes are a trap.

Features

  • Interpolating polynomial through arbitrary nodes
  • Comparison of equally spaced against Chebyshev nodes
  • Error curve plotted alongside the interpolant
  • Adjustable degree, to show divergence rather than describe it

Tech stack

Python with NumPy and Matplotlib.

Implementation

The Lagrange basis is the readable formulation but is numerically poor for repeated evaluation, so the implementation uses the barycentric form:

p(x)=∑jwjx−xjyj∑jwjx−xj,p(x) = \frac{\sum_j \dfrac{w_j}{x - x_j} y_j}{\sum_j \dfrac{w_j}{x - x_j}},p(x)=∑j​x−xj​wj​​∑j​x−xj​wj​​yj​​,

with weights computed once per node set. The evaluation is stable and cheap, and the weights make the effect of node placement explicit rather than hidden in the algebra.

Results

The demonstration reproduces the standard Runge phenomenon for equally spaced nodes and its suppression under Chebyshev spacing. This is textbook behaviour — the value here is being able to see the error curve move, not a new finding.
