RSA Wiener attack

A proof-of-concept implementation recovering small private exponents from a public key using continued fractions.

  • Cryptography
  • Number theory
  • Python
Complete

Overview

A self-contained implementation of Wiener’s attack on RSA. Given a public key whose private exponent is small relative to the modulus, it recovers the private exponent and factors the modulus, without any factoring in the usual sense.

I wrote it while learning the continued-fraction argument, and kept it because a working attack is a much better test of understanding than a proof I have read.

Features

  • Continued-fraction expansion of the public exponent over the modulus
  • Candidate testing against the quadratic whose roots are the prime factors
  • Key generation for deliberately vulnerable parameters, for testing
  • Test suite covering both vulnerable and safe keys

Tech stack

Python, standard library only. No external dependencies, which keeps it readable as a reference implementation.

Implementation

The core loop walks the convergents of the public fraction. Each convergent supplies a candidate numerator and denominator. A candidate is accepted when it produces an integer factorisation of the modulus, which happens for exactly one convergent when the attack applies.

The interesting engineering detail is knowing when to stop: the number of convergents is logarithmic in the modulus, so an exhaustive walk is cheap and the attack either succeeds quickly or not at all.

Results

The implementation recovers keys within the classical bound and fails, as expected, outside it. It is a demonstration of a published result, not a new one.
