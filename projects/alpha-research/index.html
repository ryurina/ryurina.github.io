Overview

A working environment for evaluating candidate trading signals. The point is not the signals — it is the discipline around them: consistent universe definition, honest handling of look-ahead, and a fixed reporting format so that a promising result and a disappointing one are presented identically.

Features

  • Signal definition separated from evaluation code
  • Fixed evaluation report per signal
  • Explicit handling of the lag between information and trade
  • Sanity checks that fail loudly rather than quietly
